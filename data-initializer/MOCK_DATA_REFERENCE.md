## Vector Embeddings

All text fields will be converted to 1536-dimensional vectors using **AWS Bedrock Titan Embed Text v1** model:

- **Products**: `vt_product_name` and `vt_product_brand`
- **Clients**: `vt_client_name` and `vt_client_group`
- **Locations**: `vt_location_name`

These embeddings enable semantic similarity searches, allowing you to find:
- Similar products (e.g., all dairy products)
- Similar brands (e.g., brands similar to Lala)
- Similar clients (e.g., restaurants similar to each other)
- Similar locations (e.g., metropolitan areas)
